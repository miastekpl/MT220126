🎯 SPECYFIKACJA TECHNICZNA
═══════════════════════════════════════════════════════════════════════════════

HARDWARE:
  • Mikrokontroler: ESP32-S3 N16R8 (Xtensa dual-core 240MHz)
  • Pamięć Flash: 16 MB
  • PSRAM: 8 MB (Octal SPI)
  • Wyświetlacz: ILI9341 TFT 320x240 (RGB565)
  • Enkoder: KY-040 inkrementalny (20 puls/obrót)
  • Joystick: 2-osiowy analogowy z przyciskiem
  • Przekaźniki: 6 kanałów (optoisolacja, 10A)
  • Przyciski: 18 sztuk (15 wzorców + 3 sterujące)

SOFTWARE:
  • Framework: Arduino (PlatformIO)
  • Język: C++ (standard C++11)
  • Biblioteki:
    - TFT_eSPI v2.5.43 (wyświetlacz)
    - RotaryEncoder v1.5.3 (enkoder)
    - ArduinoJson v6.21.4 (opcjonalne)
    - Preferences (EEPROM emulation)
  • Prędkość Serial: 115200 baud
  • Częstotliwość odświeżania: 10 Hz (wyświetlacz)

WYDAJNOŚĆ:
  • Dokładność pomiaru: ±1 cm (po kalibracji)
  • Czas reakcji na zmianę wzorca: < 50 ms
  • Maksymalna prędkość: 30 km/h
  • Zalecana prędkość malowania: 5-15 km/h

🚀 SZYBKI START
═══════════════════════════════════════════════════════════════════════════════

1. INSTALACJA OPROGRAMOWANIA:
   • Zainstaluj PlatformIO: https://platformio.org/
   • Rozpakuj MT220126_v1.0.0_20260123.zip
   • Otwórz folder w PlatformIO IDE lub VS Code

2. KOMPILACJA:
   Terminal: pio run
   Lub: PlatformIO → Build

3. WGRYWANIE DO ESP32:
   • Podłącz ESP32-S3 przez USB
   Terminal: pio run -t upload
   Lub: PlatformIO → Upload

4. MONTAŻ SPRZĘTOWY:
   • Szczegółowe instrukcje w docs/SCHEMATY.md
   • Mapowanie pinów w src/config.h
   • BOM (lista materiałów) w docs/SCHEMATY.md

5. KALIBRACJA (OBOWIĄZKOWA):
   • Przytrzymaj STOP (1 sek) → Menu
   • Wybierz "Kalibracja"
   • Przejedź dokładnie 10 metrów
   • Potwierdź START

6. ROZPOCZĘCIE MALOWANIA:
   • Wybierz wzorzec (przycisk P-1a do P-7d)
   • Naciśnij START/PAUZA
   • Jedź zgodnie z planem
   • System automatycznie steruje pistoletami

📋 WZORCE MALOWANIA
═══════════════════════════════════════════════════════════════════════════════

WZORCE PRZERYWANE:
  P-1a: 4m linia / 8m przerwa (12cm) - Przerywana długa
  P-1b: 2m linia / 4m przerwa (12cm) - Przerywana krótka
  P-1c: 2m linia / 2m przerwa (12cm) - Wydzielająca
  P-1d: 1m linia / 1m przerwa (12cm) - Prowadząca wąska
  P-1e: 1m linia / 1m przerwa (24cm) - Prowadząca szeroka

WZORCE CIĄGŁE:
  P-2a: Ciągła (12cm) - Ciągła wąska
  P-2b: Ciągła (24cm) - Ciągła szeroka

WZORCE ODWRACALNE (przycisk REVERSE):
  P-3a: 4m linia / 2m przerwa (12cm) - Przekraczalna długa *
  P-3b: 1m linia / 1m przerwa (12cm) - Przekraczalna krótka *

WZORCE SPECJALNE:
  P-4: Ciągła podwójna (2x12cm) - Podwójna ciągła
  P-6: 4m linia / 2m przerwa (12cm) - Ostrzegawcza

WZORCE KRAWĘDZIOWE:
  P-7a: 1m linia / 1m przerwa (24cm) - Krawędziowa przeryw. szer.
  P-7b: Ciągła (24cm) - Krawędziowa ciągła szer.
  P-7c: 1m linia / 1m przerwa (12cm) - Krawędziowa przeryw. wąska
  P-7d: Ciągła (12cm) - Krawędziowa ciągła wąska

* Wzorce odwracalne - można zmienić stronę linii ciągłej
